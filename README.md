## 🎭 AR Livestream Overlay System

**NEW:** This repository now includes a complete **AR Livestream Overlay System** for content creators!

📁 **Location:** `ARLivestreamOverlay/`  
📖 **Documentation:** See [AR_LIVESTREAM_MASTER_DESIGN.md](AR_LIVESTREAM_MASTER_DESIGN.md)  
🚀 **Quick Start:** See [ARLivestreamOverlay/README.md](ARLivestreamOverlay/README.md)

### Features
- ✨ Real-time AR overlay over live camera feed
- 👋 Gesture recognition (7 gestures via MediaPipe)
- 🎤 Voice commands (5 commands via Vosk)
- 🎬 5-state machine (IDLE, HOST_DETECTED, INTERACTION, OVERDRIVE, COOLDOWN)
- 📺 OBS Virtual Camera + RTMP streaming output
- ⚡ 30-60 FPS performance

### Tech Stack
- Unity 2022.3 LTS
- AR Foundation 5.x
- Google MediaPipe
- Vosk Speech Recognition
- Universal Render Pipeline
